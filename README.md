# Аудит безопасности домашней сети с помощью nmap

Практическая лабораторная работа по исследованию локальной сети, обнаружению активных хостов и анализу запущенных сервисов с помощью Kali Linux и сканера Nmap.

## 🎯 Цели работы:
1. Изучить принципы работы сетевого сканера Nmap
2. Научиться переводить ВМ из режима NAT в Bridged для полноценного взаимодействия с локальной сетью.
3. Обнаружить активные устройства в домашней подсети
4. Провести идентификацию операционных систем и версий запущенных служб.
